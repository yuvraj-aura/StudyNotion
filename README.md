# ?? StudyNotion — EdTech Web Application

**StudyNotion** is a modern, responsive e-learning platform frontend built with React and Vite. It offers a clean, dark-themed user interface inspired by real-world EdTech platforms, featuring rich typography, interactive course pathway previews, authentication flows, and contact channels.

---

## ? Features

- ?? **StudyNotion Dark Design System**: Custom theme with high-contrast colors and responsive layouts built using pure, clean CSS (no external UI frameworks).
- ?? **Multi-Page Routing**: Seamless navigation powered by React Router across **Home**, **About Us**, **Contact Us**, **Sign In**, **Sign Up**, and **Dashboard**.
- ?? **Authentication System**:
  - **Sign In & Sign Up** forms with Student/Instructor role toggling.
  - Interactive password visibility toggles.
  - Google Sign-In button integration and responsive visual layout with backdrop image frames.
- ?? **Rich Landing & Info Pages**:
  - **Home**: Hero section with interactive code playground preview, metrics/statistics bar, key platform features, and popular learning tracks.
  - **About Us**: Founding story, mission/vision showcase, and core principles.
  - **Contact Us**: Multi-channel support details and an interactive contact query form with Toast notifications.
- ?? **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

---

## ??? Tech Stack

- **Frontend**: React 19, Vite
- **Routing**: React Router DOM
- **Icons**: React Icons (`react-icons`)
- **Notifications**: React Toastify (`react-toastify`)
- **Styling**: Pure Modular CSS

## ?? Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yuvraj-aura/StudyNotion.git
   ```

2. Navigate to the project directory:
   ```bash
   cd StudyNotion
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
